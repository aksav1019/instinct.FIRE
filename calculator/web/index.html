How the numbers work

SIP

You invest the same amount at the start of every month. Each instalment grows at the monthly rate (yearly return ÷ 12).

Value = P × [(1 + i)n − 1] ÷ i × (1 + i)

P = monthly amount, i = yearly return ÷ 12 ÷ 100, n = years × 12. This is the same method Groww and most fund-house calculators use.

Lumpsum

You invest once and it compounds every year.

Value = P × (1 + r)t

Goal mode

The same formulas, run backwards: we start from the target and solve for the amount you need to put in today, or every month.

Check: put the answer back into "What will it grow to?" and you land on your target.
